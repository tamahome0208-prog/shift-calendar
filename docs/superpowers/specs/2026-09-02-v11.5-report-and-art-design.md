# シフトカレンダー v11.5「月末レポート + 年間軌跡アート」設計

**日付**: 2026-09-02
**ターゲット**: https://tamahome0208-prog.github.io/shift-calendar/
**スコープ**: 記憶を残す系のうち月末レポートと年間軌跡アートの 2 機能。写真日記は保留、リアルタイム系(相手カーソル/重ねタッチ)は v11.7 に分割
**コミット計画**: 2-3コミット、合計 ~330行

---

## 0. なぜやるか

v11.0 でカレンダー日常利用体験は整った。v11.5 は "**振り返って、二人で見返して、共有して楽しむ**" 層。

- 月末レポート: 「今月二人はどれくらい会えたか」を SNS ライクなカードで可視化。LINE 共有想定
- 年間軌跡アート: 1年間のシフトを1枚の Generative Art にして、共通の記憶を"作品"にする

これらは書き込みを増やさないため Firestore コストゼロ、既存データのみ活用。

---

## 1. アーキテクチャ

| レイヤ | 内容 |
|---|---|
| データ層 | 既存 `getMergedEvents()` / `allAnniversaries` / `firestoreNotes` を read-only 参照 |
| 集計層 | `Report.build(year, month)` / `Art.build(year)` の純関数で描画命令オブジェクト生成 |
| 描画層 | Canvas 2D(レポート、1080×1920 PNG)/ SVG(アート、レスポンシブ 400px 高) |
| 出力層 | `Web Share API`(対応端末)/ `<a download>` フォールバック |
| UI 層 | 履歴シート内「今月のレポート」ボタン+ overlay / 年間ビュー下に軌跡アートセクション埋め込み |

**個人情報の扱い:**
- 全てローカル生成、外部送信ゼロ
- 生成した PNG/SVG は Web Share でユーザー自身が LINE/写真アプリ等に選んで送るだけ
- Firestore 書き込みなし、rules 変更なし

**依存関係:**
- pdfjs-dist(v10.5 で既に導入)は不使用
- Canvas 2D、SVG は標準 API のみ
- Web Share API は Chrome/Safari iOS 対応、fallback で `<a download>`

## 2. コンポーネント分解

| ユニット | 責務 | 入力 | 出力 |
|---|---|---|---|
| `Report.build(year, month)` | 該当月の集計 | year, month | `{kWork, yWork, both, highlights[], events[], notesCount}` |
| `Report.drawCanvas(data, canvas)` | 縦カード描画 | build 出力 + canvas element | Blob (PNG) |
| `openReportSheet(year, month)` | overlay 開閉+ドラフト表示 | year, month | Promise<void> |
| `Art.build(year)` | 365日分の座標+色+マーカー生成 | year | `{days: [{d, x, y, kouki, yui, both, anniv}], months: [...]}` |
| `Art.renderSVG(data, svgRoot)` | SVG 要素挿入 + アニメ | build 出力 + svg root | void |
| `openArtDialog(year)` | 年切替+PNG出力ボタン | year | Promise<void> |
| `svgToPng(svgElement, width, height)` | SVG → PNG Blob 変換 | SVG element + サイズ | Blob (PNG) |

**インターフェース例:**

```javascript

```

## 3. 月末レポート 詳細

### 3-1. エントリポイント

**履歴シート**の上部に「今月のレポート」ボタン追加。デフォルトで現在月、月切替セレクタで過去月も選択可。

配置例:
```
[履歴シート]
  ┌────────────────────┐
  │ 予定リスト         [×] │
  │ [今月のレポート(8月)]  │  ← 新規
  │ 過去 X件 / 未来 Y件   │
  └────────────────────┘
```

### 3-2. カードデザイン(1080×1920px 縦)

セクション構成:
1. **ヘッダー** — 年月 + シーズンアクセント色帯 + 🌸/☔/🍁 等の月別絵文字
2. **メインカウンター** — こうき / ゆい / 被り の3枚カード(既存 summary card の Canvas 版)
3. **ハイライトリスト** — 記念日/給料日/被り日ハイライト、最大 4 項目
4. **気になる出来事** — 連続被り日 or 交換日記メッセージ数 or 出店回数
5. **フッター** — `💗 karenda by ふたり` ロゴ

**フォント:** system-ui / -apple-system / sans-serif(端末デフォルト、フォントロード不要)
**カラー:** 既存 CSS 変数から抽出、月のシーズンアクセント色を強調

### 3-3. 集計ロジック

```javascript
Report.build(year, month) {
  const merged = getMergedEvents();
  const daysInMonth = new Date(year, month + 1, 0).getDate();
  const prefix = `${year}-${String(month + 1).padStart(2, '0')}-`;
  const OFF_LABELS = new Set(['休', '希望休', '有']);

  const kOff = new Set(), yOff = new Set();
  const outings = [], meetings = [];
  for (const [key, evs] of Object.entries(merged)) {
    if (!key.startsWith(prefix)) continue;
    for (const e of evs) {
      if (OFF_LABELS.has(e.summary)) {
        if (e.person === 'こうき') kOff.add(key);
        if (e.person === 'ゆい') yOff.add(key);
      }
      if (e.summary === '出店') outings.push({key, person: e.person});
      if (e.summary === '会議') meetings.push({key, person: e.person});
    }
  }

  const bothOffKeys = [...kOff].filter(k => yOff.has(k));
  const kWork = daysInMonth - kOff.size;
  const yWork = daysInMonth - yOff.size;

  // ハイライト
  const highlights = [];
  const anniv = allAnniversaries.find(a => a.month === month + 1);
  if (anniv) highlights.push({icon: '🎂', text: `${anniv.name}(${anniv.month}/${anniv.day})`});
  // 給料日: merged の該当月 events から person=='給料' を検索
  const salary = Object.entries(merged).find(([k, evs]) => k.startsWith(prefix) && evs.some(e => e.person === '給料'));
  if (salary) highlights.push({icon: '💰', text: `給料日 ${salary.getMonth()+1}/${salary.getDate()}`});
  if (bothOffKeys.length >= 5) highlights.push({icon: '💗', text: `${bothOffKeys.length}日一緒にお休み`});
  if (outings.length) highlights.push({icon: '📅', text: `出店 ${outings.length}回`});

  // 気になる出来事
  const notable = [];
  const consecutive = findConsecutiveBothOff(bothOffKeys);  // helper
  if (consecutive.length >= 2) notable.push(`${consecutive[0]}-${consecutive[consecutive.length-1]} ${consecutive.length}日連続被り`);
  const notesMonth = Object.entries(firestoreNotes).filter(([k]) => k.startsWith(prefix));
  const msgCount = notesMonth.reduce((s, [_, d]) => s + (d.messages?.length || 0), 0);
  if (msgCount >= 5) notable.push(`交換日記 ${msgCount}メッセージ`);

  return { year, month, kWork, yWork, both: bothOffKeys.length, highlights, notable, seasonEmoji: getSeasonEmoji(month + 1) };
}
```

### 3-4. Canvas 描画

- 全てのテキスト・矩形・グラデを Canvas 2D API で描画
- カラー: `getComputedStyle(document.body)` から `--cheek`, `--leaf`, `--kouki` 等を取得
- 各要素は関数化: `drawHeader(ctx, data)`, `drawCounters(ctx, data)`, `drawHighlights(ctx, data)`, `drawFooter(ctx)`

### 3-5. 出力

- `canvas.toBlob(blob => ...)` で PNG Blob 取得
- `shareOrDownload(blob, `${year}-${String(month+1).padStart(2,'0')}-report.png`)` で処理

## 4. 年間軌跡アート 詳細

### 4-1. 埋め込み位置

年間ビュー(既存)の**下**に SVG 要素を追加。年切替(2025/2026)ボタンで再描画。

### 4-2. ビジュアル

**キャンバス:** SVG、`viewBox="0 0 1200 400"`、幅 100%

**構造:**
- **X軸:** 1日目〜365日目、`x = day * (1200 / 365)`
- **中央線** (`y=200`) を基準に:
  - **こうき労働日** = 上向き短線(青系グラデ)
  - **ゆい労働日** = 下向き短線(ピンク系グラデ)
  - **こうき+ゆい両方休日 (両休み)** = 中央に光る円(半径可変)
  - **記念日** = 大きな★マーカー
- **月境界** = 薄い縦線 + 上部に月名(1月, 2月, ...)
- **背景** = 現在時刻の時間帯背景をベースに透過度 0.3 で敷く

**カラーパレット:**
| 要素 | 色 |
|---|---|
| こうき線 | `linear-gradient(var(--kouki-meeting), #1B5577)` |
| ゆい線 | `linear-gradient(var(--yui-meeting), #B91C5C)` |
| 被り円 | `radial-gradient(var(--leaf), var(--leaf-deep))` + フィルタ `drop-shadow(0 0 4px var(--leaf))` |
| 記念日★ | `var(--cheek-deep)` |
| 月境界 | `rgba(0,0,0,0.08)` |

### 4-3. 集計ロジック

```javascript
Art.build(year) {
  const merged = getMergedEvents();
  const startDate = new Date(year, 0, 1);
  const endDate = new Date(year, 11, 31);
  const days = [];
  const OFF_LABELS = new Set(['休', '希望休', '有']);

  for (let d = 0; d < 365; d++) {
    const date = new Date(year, 0, 1 + d);
    const key = dateKey(date.getFullYear(), date.getMonth(), date.getDate());
    const evs = merged[key] || [];
    const kOff = evs.some(e => e.person === 'こうき' && OFF_LABELS.has(e.summary));
    const yOff = evs.some(e => e.person === 'ゆい' && OFF_LABELS.has(e.summary));
    const both = kOff && yOff;
    const anniv = allAnniversaries.find(a => a.month === date.getMonth() + 1 && a.day === date.getDate());
    days.push({
      d,
      date: key,
      kouki: !kOff,
      yui: !yOff,
      both,
      anniv,
    });
  }

  const months = [];
  for (let m = 0; m < 12; m++) {
    const firstDay = new Date(year, m, 1);
    const dayIdx = Math.floor((firstDay - startDate) / (24 * 60 * 60 * 1000));
    months.push({ m, dayIdx, name: `${m + 1}月` });
  }

  return { year, days, months };
}
```

### 4-4. SVG 生成

- `Art.renderSVG(data, svgRoot)` で以下を挿入:

  - こうき線 = 出勤日ごとに `<line y1=200 y2=180>` (labor時間で伸ばすのは v11.7)
  - ゆい線 = `<line y1=200 y2=220>`
  - 被り円 = `<circle cx=x cy=200 r=6>`
  - 記念日★ = `<polygon points=...>` for star shape

## 5. 共通ユーティリティ

### 5-1. svgToPng

```javascript
async function svgToPng(svgEl, width, height) {
  const svgString = new XMLSerializer().serializeToString(svgEl);
  const blob = new Blob([svgString], { type: 'image/svg+xml' });
  const url = URL.createObjectURL(blob);
  const img = new Image();
  await new Promise((res, rej) => { img.onload = res; img.onerror = rej; img.src = url; });
  const canvas = document.createElement('canvas');
  canvas.width = width;
  canvas.height = height;
  const ctx = canvas.getContext('2d');
  ctx.drawImage(img, 0, 0, width, height);
  URL.revokeObjectURL(url);
  return await new Promise(res => canvas.toBlob(res, 'image/png'));
}
```

### 5-2. shareOrDownload

```javascript
async function shareOrDownload(blob, filename) {
  if (navigator.canShare && navigator.canShare({ files: [new File([blob], filename, { type: 'image/png' })] })) {
    try {
      await navigator.share({ files: [new File([blob], filename, { type: 'image/png' })], title: 'karenda' });
      return;
    } catch (e) {
      if (e.name !== 'AbortError') console.error(e);
    }
  }
  // Fallback: download
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = filename;
  a.click();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
}
```

## 11. ロールバック条件

- Canvas 描画エラー → try/catch で「レポート生成失敗」表示、既存機能に影響なし
- SVG 描画で大量 DOM 挿入によるフリーズ → 365 要素は少量なので想定内、実測で 1秒超なら分割
- HTMLサイズ 20% 超 → C1/C2 のいずれかを revert
- 既存機能の regression → 該当コミット revert
